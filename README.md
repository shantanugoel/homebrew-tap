# homebrew-tap

Homebrew formulae for my tools.

```sh
brew tap shantanugoel/tap
brew install skillmeister
```

| Formula | What it is |
|---|---|
| `skillmeister` | Local library of agent skills with one router entry point. [Source](https://github.com/shantanugoel/skillmeister) |

The Ganit cask lives in [homebrew-ganit](https://github.com/shantanugoel/homebrew-ganit).
